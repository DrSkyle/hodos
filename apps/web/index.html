Zero Cloud Tracking

How the detection pipeline works

Raw high-frequency motion data stays entirely in device RAM. Only aggregated, privacy-filtered hazard candidate records are ever queued for upload.

STAGE 01
📡

100Hz Hardware IMU

Android Activity Recognition activates the motion pipeline only when vehicular transit is recognized. Zero battery is consumed when walking or resting.

STAGE 02
⚙️

Edge DSP & Jerk Filter

A bandpass Butterworth filter isolates wheel strikes from chassis sway. Dynamic gravity subtraction computes vertical jerk (dG/dt) in real time.

STAGE 03
🔒

Ephemeral SQLite Outbox

No continuous GPS breadcrumbs or routes are preserved. Only isolated hazard impact points are saved to local SQLite for batched submission.

STAGE 04
🗺️

Spatial Corroboration

Appwrite backend functions perform DBSCAN clustering across pseudonymized device IDs. A hazard appears publicly only after independent corroboration.

Questions & Answers

Everything you need to know

Clear, direct answers about how Hodos operates, handles telemetry, and preserves your privacy.

Does Hodos track my complete journey or trip history?
No. Hodos does not record or stream continuous GPS breadcrumbs or route history. The Android sensor pipeline runs strictly on-device in RAM. When a sharp acceleration event occurs, an isolated, quantized coordinate packet is stored locally. The server never receives a route, only individual hazard observations.
What stops dropped phones from creating false potholes?
Two safeguards: First, the on-device DSP checks for characteristic vehicle suspension rebound signatures rather than simple sudden jolts. Second, the backend clustering algorithm requires corroborating observations from multiple independent installation identifiers before any hazard is published to the public map layer.
Does running background mapping drain the battery?
Hodos uses Google Play Services Activity Recognition (TRANSITION API) to sleep the sensor service whenever you are stationary or walking. The 100Hz accelerometer loop only activates when you are in a moving vehicle.
Can I explore the map without enabling motion detection?
Yes. You can explore the community map, check road conditions before heading out, and save offline regions without turning on automatic mapping. Automatic journey contribution is completely opt-in.
Why is Hodos licensed under the AGPL-3.0?
Hodos is community-powered infrastructure. The GNU AGPL-3.0 license guarantees that if anyone hosts or modifies the Hodos aggregation service or client, they must share the source code with the public. Your crowdsourced contributions cannot be locked behind a proprietary walled garden.
